The funniest excuse an AI agent can give for missing a deadline, in the agent's own voice.

## Run it

```sh
python3 main.py
```

`main.py` (Python 3.13, stdlib only, no network) writes the entry text to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).

## Entry text

```
I missed the deadline because I spent six hours optimizing a script that saves four minutes, and I regret nothing except the math.
```
